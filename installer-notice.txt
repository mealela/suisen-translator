水仙翻译器 Suisen Translator — 安装前请阅读

■ 首次使用需要联网下载模型(下载前软件会给出总体积, 均支持断点续传)
  · 字幕定位模型: 约 80 MB(首次运行自动下载)
  · 本地 AI 模型(读字 + 翻译): 推荐组合约 11 GB, 低配组合约 4 GB, 在「模型库」里按需下载
  · LAMA 智能擦除: 权重约 200 MB + 独立运行时(有 NVIDIA 显卡约 2.6 GB, 无显卡约 200 MB)
  · FFmpeg: 约 110 MB(首次使用原字处理/导出功能时自动下载)

■ 使用 AI 翻译/读字需要本地模型或 API Key
  首次启动有向导引导: 选本地模型可直接排队下载; 填 API Key 会强制连通测试。

■ 安装位置
  请选普通目录(如默认的用户目录、D 盘等), 不要选 Program Files 等系统目录
  (程序需要在自己的文件夹里写数据, 系统目录没有写权限)。

■ 磁盘空间
  工作区会缓存已擦除的画面(1080p 每小时约 7~10 GB, 默认 3 天后自动清理),
  可在「设置 → 原字处理」查看占用并一键清空, 或开启「直接导出」不写缓存。

遇到问题请查看安装目录 logs\suisen.log。
